# Source Conflicts

Record disagreements between sources here. Conflicts are not defects to erase; they are part of the fanmade knowledge landscape.

## Record

- Conflict ID
- Subject/mechanic
- Claims involved
- Each source and exact reference
- Game-version scope for each source
- Publication/update and access dates
- Difference type (value, formula, condition, unit, timing, terminology, or interpretation)
- Whether the sources actually describe the same context
- Known limitations
- Current state: open, partially explained by version/context, or no longer applicable

## Policy

1. Preserve each source's claim verbatim or faithfully summarized.
2. Do not select a winner merely because one source is newer or more popular.
3. Assess authority and recency separately.
4. If versions differ, retain both version-scoped claims.
5. If scope cannot be aligned, mark the conflict as context-unresolved rather than declaring a contradiction.
6. Do not average or silently normalize values.
