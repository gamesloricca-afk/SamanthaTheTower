
# TheTowerData Reports

This directory stores preservation, import, and validation reports.

Each report should identify:

- Operation performed.
- Source SDK version.
- Upstream commit.
- Date.
- Files included.
- Files excluded.
- Licensing assessment.
- Checksum verification.
- Import result.
- Errors and limitations.

Reports must distinguish:

- VERIFIED
- INFERRED
- HYPOTHESIS
- NOT TESTED
- BLOCKED

Never report a successful import or validation unless it was executed.
