# Domain Investigations

This directory contains one investigation workspace per GRE knowledge domain.

## Current order

1. [Domain 04 — Combat Mechanics](04-combat-mechanics/README.md) — first investigation.
2. Domain 02 — Enemies — next, with cross-references back to Combat Mechanics.
3. Remaining domains follow the staged order in [Evidence Expansion README](../README.md).

## Domain workspace expectations

Each domain README should define:
- GRE source files and structural audit references;
- declaration-level investigation leads;
- cross-domain leads;
- source types to seek;
- claim topics to investigate;
- unknowns and evidence gaps;
- status and next actions.

Do not copy an entire GRE JSON into the evidence workspace. Link to the original and record only the findings and evidence needed for investigation.
